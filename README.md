### Q2. Library Implementation

### Q3. IEEE 754 與 -ffast-math
GCC 編譯器存在一個叫做 `-ffast-math` 的參數 ，這有什麼用？詳細的介紹關閉與開啟此選項的差異，並給出與解釋一個僅因為有無開啟 `-ffast-math` 選項 ，而導致計算結果發生改變的例子。

### Q4. 浮點數輸出
